# 微博评论情感分类

读取微博评论爬虫输出的 JSON 文件，对每条评论进行情感分析，
按正面反馈（期待/喜欢/感谢）、负面反馈（讨厌/抱怨/担忧）、中性（询问/事实陈述）三类归类，
输出 EXCEL 统计报告。**每次运行后自动反思并更新词典库**，词库随使用逐渐进化。

所有命令从 **MediaCrawler 项目根目录** 执行。

## 依赖

```bash
cd MediaCrawler
uv pip install openpyxl
```

## 快速开始

```bash
cd MediaCrawler
uv run python ../.claude/skills/weibo-sentiment-classifier/scripts/sentiment_classifier.py \
    --input "../WeiboExtractData/广州天气/2026-05-22/广州天气_20260522.json"
```

## 完整参数

| 参数 | 是否必填 | 说明 |
|---|---|---|
| `-i` / `--input` | 必填 | 微博评论爬虫输出的 JSON 文件路径 |
| `-o` / `--output` | 可选 | EXCEL 输出路径（默认在输入文件同目录自动生成） |
| `--no-update` | 可选 | 跳过词典库的自动反思更新（仅分类，不改词库） |
| `--dict-stats` | 可选 | 仅查看词典库统计信息（不分类） |

## 本地词典库

词典库文件 `scripts/sentiment_dict.json`，独立于主脚本维护，包含：

```
{
  "meta": { ... },              // 版本号、运行次数、累计分析评论数
  "positive_words": { ... },    // 正面词 → {count, added_in_version}
  "negative_words": { ... },    // 负面词 → {count, added_in_version}
  "neutral_greetings": { ... }, // 中性问候语 → {count, added_in_version}
  "patterns": { ... },          // 否定词、程度副词、问句标记等模式规则
  "pending_candidates": { ... } // 待审核候选新词
}
```

每个情感词附带 `count` 字段记录历史触发次数，**次数越高表示越可信**，在分类时享有更高的评分权重。

## 置信度权重

| 触发次数 | 权重 | 说明 |
|---|---|---|
| 0 (冷启动) | 0.6× | 新词，保守对待 |
| 1-5 | 0.8× | 初步验证 |
| 6-20 | 1.0× | 标准权重 |
| 21-50 | 1.3× | 可信词 |
| 51-100 | 1.6× | 高频词 |
| >100 | 2.0× | 核心词 |

## 自动反思机制

每次分类完成（非 `--no-update` 模式）后：

1. **更新触发计数** — 本次所有被匹配到的词，`count` 递增
2. **边界检测** — 记录 |score|<=1.5 的模糊案例，打印报告供人工复查
3. **候选词发现** — 从未匹配评论中提取高频 n-gram，存入 `pending_candidates`
4. **生成反思报告** — 打印本次触发词 Top10、边界案例、候选新词

## 输出格式

EXCEL 包含两个 Sheet：

### 汇总

| 列 | 说明 |
|---|---|
| 微博作者名称 | 帖子作者昵称 |
| 发布时间 | 帖子创建时间 |
| 微博内容 | 帖子正文 |
| 点赞数 | 帖子点赞数 |
| 评论数 | 有效评论总数 |
| 正面/负面/中性 数量 | 各类情感评论数 |
| 正面/负面/中性 占比 | 百分比 |

### 评论明细

| 列 | 说明 |
|---|---|
| 微博作者 | 帖子作者昵称 |
| 微博内容 | 帖子正文 |
| 评论者 | 评论者昵称 |
| 评论内容 | 评论正文 |
| **情感分数** | 加权后的情感分值（正=正面，负=负面，零=中性） |
| 情感分类 | 正面 / 负面 / 中性 |
| 点赞数 | 评论点赞数 |

## 分类规则

1. **纯问候语优先** — "晚上好""晚安""你好"等直接判为中性
2. **词典最长匹配** — 4→3→2→1 字逐级匹配情感词
3. **置信度加权** — 基础分 × 词频置信度权重 × 程度副词放大
4. **否定反转** — 不/没/无/别 + 正面词 → 负面；否定 + 负面词 → 不计分
5. **问句降权** — 含 吗/呢/？/什么/怎么 且情感分微弱 → 中性
6. **问句语境词** — "安心""放心""方便"等条件性正面词在问句中不计分

## 注意事项

- 词典库会随每次运行自动更新，建议定期提交 `sentiment_dict.json` 以共享词库进化
- 使用 `--no-update` 可在不修改词典的情况下进行分类（如测试/调试）
- `--dict-stats` 可随时查看词典健康度和高频词排名
