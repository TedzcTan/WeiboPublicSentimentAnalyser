# 微博评论话题聚类

读取微博评论爬虫输出的 JSON 文件，对所有评论进行 AI 语义聚类分析，
识别用户最关心的核心话题，输出结构化的话题分析结果。

## 前置脚本

使用 `scripts/extract_comments.py` 从 JSON 中提取代表性评论，供 AI 聚类使用：

```bash
cd MediaCrawler
uv run python ../.claude/skills/weibo-topic-clusterer/scripts/extract_comments.py \
    --input "../WeiboExtractData/深圳天气/2026-05-20/深圳天气_20260520.json" \
    --input "../WeiboExtractData/深圳天气/2026-05-21/深圳天气_20260521.json" \
    --sentiment "../WeiboExtractData/深圳天气/2026-05-20/深圳天气_20260520_情感分析.xlsx" \
    --max-comments 200 --format text
```

参数说明：
| 参数 | 说明 |
|---|---|
| `--input` / `-i` | 爬取结果 JSON 文件（可多次指定） |
| `--sentiment` / `-s` | 情感分类 EXCEL 文件（可选，可多次指定） |
| `--max-comments` / `-n` | 最大提取评论数（默认 200） |
| `--format` | 输出格式：`json` 或 `text`（纯文本，适合 AI 阅读） |

## 输入

微博评论爬虫输出的 JSON 文件路径。可通过 `extract_comments.py` 预处理后输入。

## 分析流程

### 1. 准备数据

运行 `extract_comments.py` 提取代表性评论（按点赞数排序 + 随机采样），
将输出的评论文本加载到上下文中。

### 2. 全量评论扫描

统计评论总数，将 `extract_comments.py` 输出的评论内容和上下文加载到上下文中。

### 3. 语义聚类

分析所有评论内容，归纳出 **3-5 个核心关切话题**。要求：

- **话题粒度适中**：不能太细（如"下雨天鞋子湿了"和"下雨天衣服不干"应归为"雨天生活困扰"），也不能太粗（如全部归为"天气相关"）
- **命名清晰**：话题名应直接反映用户关切点，如"雨何时转晴""出行不便""预警准确性质疑"
- **涵盖主要评论**：每个话题应覆盖一定比例的评论，优先提取高频关切

### 4. 关键词匹配计数

对每个识别出的话题，定义一组关键词（5-10个），对所有评论做关键词匹配，
得出每个话题的**精确提及次数**。
如果一条评论匹配多个话题，计入最相关的话题。

### 5. 提取代表评论

每个话题选出 2-3 条最能代表该话题的典型评论作为示例。

### 6. 分析情感倾向

对每个话题，统计该话题下评论的正/负/中情感分布。

## 输出格式

分析完成后，按以下格式输出结果：

```
## 核心关切话题

### 话题1: {话题名}（提及 {次数} 次）
**情感倾向**: {正面为主 / 负面为主 / 中性为主}（正面{百分比}%，负面{百分比}%，中性{百分比}%）
**话题描述**: {一句话概括用户在该话题下的主要观点}
**代表评论**:
- "{评论1}"
- "{评论2}"
- "{评论3}"

### 话题2: {话题名}（提及 {次数} 次）
...
```

## 注意事项

- 话题数量根据评论总量动态调整：少于100条评论通常2-3个话题，100-500条约3-4个，500条以上3-5个
- 关键词匹配时应考虑同义表达（如"雨停""放晴""转晴""出太阳"视同一类）
- 情感分类参考 sentiment_classifier 的结果（如果已运行），或自行判断
- 如果评论量极少（<10条），跳过聚类，直接说明评论量不足
